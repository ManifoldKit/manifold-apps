# Changelog

## 0.1.0 — TestFlight candidate

The first Manifold minor is an internal TestFlight build for real-device
validation. It is not yet a public App Store release.

- Consumer chat on iOS with persisted sessions and model management.
- Cloud endpoint, tool approval, theming, and App Intent showcase surfaces.
- Manifold on macOS with MLX and llama.cpp local inference.
- Published dependency floors: ManifoldKit 0.76.0, manifold-mlx 0.5.2, and
  manifold-llama 0.4.5.
